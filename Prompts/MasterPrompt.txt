============================================================
1. FINAL PROJECT DEFINITION
============================================================

Build an NLP-based four-class classification system that accepts
social-media text/tweet text as input and predicts one of four
categories:

1. Regular
2. Sarcasm
3. Irony
4. Figurative

Meaning:

Regular:
Normal/non-figurative text.

Sarcasm:
Text containing sarcastic expression.

Irony:
Text containing ironic expression.

Figurative:
Text representing the combined/figurative category in the
selected dataset, associated with sarcasm + irony.

The main task is:

TEXT
  ↓
NLP PROCESSING
  ↓
FEATURE REPRESENTATION
  ↓
CLASSIFICATION
  ↓
ONE OF FOUR CLASSES

Formally:

f(text) → {Regular, Sarcasm, Irony, Figurative}

55. DATA LEAKAGE RULES
============================================================

Never:

- fit TF-IDF on test data
- tune models using test data
- train BERT on test data
- use test examples for hyperparameter selection
- use duplicate test examples that leaked from training without
  explicitly handling them
- calculate preprocessing vocabulary using the full dataset

Correct:

Training data
 ↓
fit preprocessing
 ↓
transform validation
