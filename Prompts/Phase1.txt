============================================================
13. STEP 9 — DATA LEAKAGE ANALYSIS
============================================================

Determine whether the train/test overlap creates evaluation leakage.

Explain:

If an identical tweet occurs in both training and test,
the model may effectively see the test example during training.

Therefore, such overlap can inflate test performance.

Do NOT hide this problem.

Do NOT simply report the original test score later without
documenting the overlap.

============================================================
14. STEP 10 — DECISION FOR TRAIN/TEST OVERLAP
============================================================

For the working clean dataset, the preferred strategy is:

- Preserve original raw train/test files.
- Create a cleaned training dataset.
- Create a leakage-controlled evaluation dataset.
- Remove or exclude exact train/test text overlaps from the
  final clean test evaluation set.
- Document exactly how many records were excluded.
- Do not move test records into training.
- Do not duplicate data.

The original test dataset must remain available for reference.

If there is a better academically justified approach after inspecting
the exact overlap structure, explain it before implementing it.

The goal is:

FINAL TEST EVALUATION MUST REPRESENT UNSEEN TEXT.
