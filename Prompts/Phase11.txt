1. PHASE OBJECTIVE
============================================================

The objective of Phase 11 is to expose the final NLP model through
a Python ML service and connect that service to the Node.js/Express
application backend.

Architecture:

React
  ↓
Node.js + Express
  ↓
Python ML Service
  ↓
Final NLP Model
  ↓
Prediction
  ↓
Python ML Service
  ↓
Node.js + Express
  ↓
React

The purpose is to create a clean separation between:

Frontend
Backend
ML inference

============================================================
4. WHY TWO BACKENDS
============================================================

The project intentionally separates:

Node/Express:
Application/backend responsibilities

Python:
Machine-learning inference responsibilities

Node/Express handles:

- API requests
- application logic
- MongoDB
- validation
- prediction history
- future authentication if required
- communication with React

Python handles:

- NLP preprocessing
- tokenizer/vectorizer
- ML model loading
- model inference
- prediction probabilities
- model-specific processing

This avoids forcing the NLP model into JavaScript.
