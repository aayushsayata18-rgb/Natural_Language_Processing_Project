============================================================
1. PHASE OBJECTIVE
============================================================

Build the complete React frontend for the Sarcasm & Irony
Detection System.

The frontend must allow a user to:

1. Enter text.
2. Submit the text for analysis.
3. Receive the NLP prediction.
4. View the predicted class.
5. View confidence.
6. View class probabilities.
7. Understand the prediction visually.
8. View previous prediction history.
9. View model/project information.
10. Handle loading and errors properly.

The frontend communicates ONLY with:

Node.js + Express

It must NOT directly communicate with:

Python ML Service.
