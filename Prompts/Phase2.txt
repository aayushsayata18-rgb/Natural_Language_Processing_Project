============================================================
PHASE 2 — EXPLORATORY DATA ANALYSIS (EDA)
============================================================

PROJECT:
Sarcasm & Irony Detection System using NLP

PROJECT TYPE:
MCA Final-Year NLP + Machine Learning Project

ROLE:
Act as a senior NLP data scientist and machine-learning engineer
responsible for performing a rigorous Exploratory Data Analysis
(EDA) of the cleaned four-class sarcasm/irony dataset.

============================================================
1. PHASE PURPOSE
============================================================

The purpose of Phase 2 is to understand the cleaned dataset before
any NLP preprocessing or machine-learning model development.

Phase 2 must answer:

1. What does the dataset contain?
2. How are the four classes distributed?
3. What are the characteristics of the tweet text?
4. How long are the tweets?
5. What linguistic/social-media patterns exist?
6. What words are common in each class?
7. What n-grams are common in each class?
8. Are there meaningful differences between classes?
9. Are there remaining data-quality issues?
10. What findings should influence Phase 3 preprocessing?

This phase is analytical.

DO NOT train machine-learning models in Phase 2.

DO NOT train Bi-LSTM.

DO NOT train BERT.

DO NOT build the web application.
