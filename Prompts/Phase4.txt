============================================================
PHASE 4 — BAG OF WORDS + CLASSICAL MACHINE LEARNING
============================================================

PROJECT:
Sarcasm & Irony Detection System using NLP

PROJECT TYPE:
MCA Final-Year NLP + Machine Learning Project

ROLE:
Act as a senior NLP engineer, machine-learning engineer,

You are responsible for implementing Phase 4 of the project.

============================================================
1. PHASE OBJECTIVE
============================================================

The purpose of Phase 4 is to establish strong and reproducible
classical NLP + machine-learning baselines using:

1. Bag of Words
2. Logistic Regression
3. Multinomial Naive Bayes
4. Linear Support Vector Machine

This phase provides the first real classification results.

The pipeline is:

CLEAN DATA
   ↓
PHASE 3 PREPROCESSING
   ↓
BAG OF WORDS
   ↓
FEATURE VECTORS
   ↓
CLASSICAL ML MODELS
   ↓
VALIDATION
   ↓
TEST EVALUATION
   ↓
METRICS
   ↓
CONFUSION MATRIX
   ↓
BASELINE COMPARISON

Do NOT implement BERT, Bi-LSTM, FastText, Attention, FastAPI,
React, Node.js, or MongoDB in this phase.

============================================================
2. PROJECT CLASSIFICATION TASK
============================================================

This is a four-class text classification problem.

Target classes:

1. Regular
2. Sarcasm
3. Irony
4. Figurative

The model must predict exactly one of these four classes.

The class mapping established in Phase 1 must be used consistently.

Example:

Regular     → 0
Sarcasm     → 1
Irony       → 2
Figurative  → 3

Never create a different mapping.

============================================================
5. DATA SPLIT
============================================================

The original training dataset remains the source for model training.

Create:

TRAIN
VALIDATION

from the training dataset only.

The official clean test/evaluation dataset must remain untouched
until final evaluation.

Recommended:

80% training
20% validation

Use stratification based on the four-class label.

Example:

train_test_split(
    X,
    y,
    test_size=0.20,
    stratify=y,
    random_state=42
)

Use a fixed random seed.

Do not use the official test set for hyperparameter tuning.

============================================================
6. IMPORTANT DATA LEAKAGE RULE
============================================================

Bag of Words must be fitted ONLY on the training split.

Correct:

Training text
    ↓
fit CountVectorizer
    ↓
training vectors

Validation text
    ↓
transform only

Test text
    ↓
transform only

Never:

Train + validation + test
    ↓
fit CountVectorizer

That would leak vocabulary information.

============================================================

- random_state where supported

- increase max_iter

- document the change
