============================================================
1. PHASE OBJECTIVE
============================================================

The purpose of Phase 9 is to perform a complete research-oriented
comparison of all major NLP approaches developed in the project.

Compare:

PHASE 4:
BoW + Classical ML

PHASE 5:
TF-IDF + Classical ML

PHASE 5:
TF-IDF + Linguistic/Social-Media Features

PHASE 6:
GloVe + Bi-LSTM

PHASE 7:
FastText + Bi-LSTM

PHASE 7:
FastText + Bi-LSTM + Attention

PHASE 8:
BERT

Then:

1. Compare performance.
2. Compare class-wise behavior.
3. Analyze errors.
4. Analyze computational cost.
5. Analyze model complexity.
6. Determine strengths and weaknesses.
7. Select the final model.
8. Justify the final model scientifically.
9. Prepare the project for model packaging/deployment.

============================================================
2. CORE RESEARCH QUESTION
============================================================

The central research question is:

"Which NLP representation and machine-learning/deep-learning
architecture provides the most suitable balance between
classification performance, class-level reliability,
interpretability, and computational cost for four-class
sarcasm and irony detection?"

Do NOT assume that the most complex model is automatically the best.

The final decision must be evidence-based.

============================================================

4. Best GloVe + Bi-LSTM
5. Best FastText + Bi-LSTM
6. Best FastText + Bi-LSTM + Attention
7. Best BERT

Do NOT compare every failed experiment in the main final table.

Keep all experiments in the experiment history, but use the best
valid candidate from each approach for the main comparison.

7. PRIMARY METRIC
============================================================

The primary model-selection metric is:

MACRO F1

Reason:

The project contains four classes and each class should receive
equal importance in the primary comparison.

Macro F1 should therefore be prioritized over accuracy.

Secondary metrics:

1. Accuracy
2. Macro Precision
3. Macro Recall
4. Weighted F1
5. Per-class F1

============================================================
8. WHY ACCURACY IS NOT ENOUGH
============================================================

The analysis must explicitly explain:

A model can achieve high accuracy while performing poorly on one
or more classes.

Therefore:

Accuracy alone cannot determine the best four-class classifier.

Macro F1 provides a more balanced view across:

Regular
Sarcasm
Irony
Figurative
